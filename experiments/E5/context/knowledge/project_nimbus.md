# Project Nimbus (fictional test data)

Project Nimbus is Lumen Labs' pilot of solar-powered parcel lockers for apartment buildings.
- Lead: Priya Raman. Hardware: Tomás Ortega. Software: Mei Lin.
- Pilot: 12 lockers in 3 buildings in Pune, running since 2 September.
- Each locker has a 400-watt panel and a 2 kWh battery; it runs 3 days without sun.
- Results so far: 1,840 parcels delivered, 97.6 % picked up within 24 hours, two battery faults (both fixed under warranty).
- Residents' top request: a reminder message when a parcel waits longer than a day. Planned for release 1.3 on 15 December.
- Next milestone: decide on expanding to 40 lockers by 31 January. Budget ask: 18 lakh rupees.
- Biggest risk: monsoon-season panel cleaning; the team is testing a self-cleaning coating.
