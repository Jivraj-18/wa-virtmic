E0 · Simulated caller and test harness

DONE

1The idea

Testing a voice agent by asking a friend to call every time is slow and can't be repeated. E0 replaces the human with a scripted TTS caller. It speaks lines from a YAML file, waits for the agent to answer, can interrupt it on purpose, and measures how fast the agent responds. Every other experiment uses it.

2How it works

Each run makes its own pair of sinks (suffix --tag), so several experiments can test at once without touching the real WhatsApp devices. Times are measured on the recorded audio itself, not the wall clock, so dropped audio buffers can't skew the numbers.

4Results

Latency is measured from the moment the caller's voice ends to the agent's first audible sound. It includes the model's end-of-turn detection (500 ms of silence), the network and generation time.

5What worked, what didn't, what's next

Worked

  • All 12 caller turns across the 3 scripts got a sensible spoken answer.
  • Latency is steady: median 1.2–1.4 s, p90 under 1.5 s.
  • Barge-in works: the agent stopped about 1.5 s after the caller talked over its story, then answered the new question.
  • Asked in Hindi, the agent switched to Hindi and stayed there.

Didn't

  • Stopping after barge-in (about 1.5 s) is slow: the caller hears the agent talking over them.
  • The caller's natural pauses mid-sentence end the turn too early (500 ms silence), so some replies start and are then cut off.
  • Once, mid-story, the agent switched to Hindi on its own after a misheard caller phrase.
  • The transcriber writes some short Hindi phrases in Urdu script. This is a limit of speech-to-text, not of the agent.

Next

  • Tune turn detection (longer silence, or "semantic" VAD) and compare in E3.
  • Pin the reply language unless the caller clearly switches.
  • Add a scripted-caller check of answer correctness, not just latency.

6How to run it

bash scripts/install.sh            # once per container (apt + pip)
bash scripts/audio_setup.sh        # PulseAudio daemon (idempotent)
cp scripts/.env.example scripts/.env   # add your LLM gateway URL + token

# run one scripted call against the realtime agent; --tag keeps sinks separate
python3 scripts/sim_call.py experiments/E0/scripts/basic_qa.yaml --tag E0
python3 scripts/sim_call.py experiments/E0/scripts/interruption.yaml --tag E0
python3 scripts/sim_call.py experiments/E0/scripts/hinglish.yaml --tag E0

# test any other agent: placeholders {in_device} {out_device} {transcript} {seconds} {python}
python3 scripts/sim_call.py my.yaml --tag X --agent "{python} my_agent.py --in {in_device} --out {out_device}"

# publish a run (≤ 60 s clip + transcript + metrics) to this site
python3 scripts/publish_run.py experiments/runs/E0_basic_qa_<ts> --id E0

Output per run in experiments/runs/<tag>_<script>_<ts>/: agent.wav, caller.wav, call_stereo.wav, call.mp3, transcript.txt/json, agent_transcript.txt, metrics.csv, summary.json, agent.log.
